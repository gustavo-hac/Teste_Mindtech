# Teste desenvolvimento de software Mindtech

## Introdução

O objetivo é desenvolver um sistema de inscrição em uma newsletter fictícia. O projeto será composto de duas partes, sendo elas o Front-end e o Back-end

![exemplo front](./files_provided/subscribe.png)

### Front-end

Para esta parte do projeto, estão inclusos arquivos com o design de referência e os recursos visuais necessários para a implementação. Necessário incluir instruções de como rodar o projeto.

### Back-end

O objetivo é desenvolver a API necessária para o recebimento de emails, e cadastro dos mesmos em um banco de dados. Não devem ser cadastrados emails repetidos, e isso deve ser informado para o front-end. Também deve existir uma forma de um usuário se descadastrar da newsletter. Os dados obtidos devem ser persistidos de alguma forma. Deve-se incluir instruções de como rodar o projeto.

Ambas as partes deve se integrar, e funcionar juntas.

## Requisitos

XAMPP

## Passo a passo

Baixando os arquivos:
- Baixe os arquivos no diretório do XAMPP "xampp\htdocs".

Configurando o sistema:
- Abra o XAMPP, em Actions clique em "start" para iniciar o Apache e MySQL.
- Entre em http://localhost

Configurando o banco de dados
- Entre em http://localhost/phpmyadmin/
- Clique para ir na página inicial.
- Clique em importar no menu.
- Escolha o arquivo do diretório "assets\dataBase\sql_script.sql".

Alternativa para o Banco de dados
- Cópie todos os arquivos do diretório "extra\newslleter_mindtech_ghac" para "xampp\mysql\data"

Agora só resta ir na aba do "localhost".
